처음 설정하는 방법 (1회, 관리자)
  1. Google Cloud 콘솔에서 프로젝트 하나 만들기 (이름 예: 우동지 업무).
  2. API 및 서비스 → 라이브러리 → Google Sheets API 사용 설정.
  3. API 및 서비스 → OAuth 동의 화면 → 사용자 유형 외부(개인 gmail) 또는 내부(워크스페이스). 범위는 추가 안 해도 됨. 외부면 테스트 사용자에 상담자들 이메일 추가.
  4. 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID → 유형 웹 애플리케이션.
  5. 승인된 JavaScript 원본에 이 페이지가 올라가는 주소를 넣기: {{ origin }}
  6. 생성된 클라이언트 ID를 위 칸에 붙이고, 고객 목록 시트 URL과 탭 이름을 넣고 설정 저장 → 구글 계정으로 로그인.

시트는 상담자 각자의 구글 계정 편집 권한으로 읽고 씁니다. 로그인은 브라우저 탭 기준 약 1시간 유지되고, 만료되면 다시 로그인 버튼이 뜹니다. 시트 첫 줄이 헤더여야 하고, 없는 열(레코드ID, 페이앤 등록)은 처음 전송할 때 맨 끝에 자동 추가됩니다.

이 페이지를 임시 미리보기 주소로 보고 있다면 구글이 그 주소를 원본으로 허용하지 않을 수 있어요. 실제 사용은 고정 주소(회사 서버, GitHub Pages 등)에 올린 뒤 그 주소를 원본에 등록하세요.
