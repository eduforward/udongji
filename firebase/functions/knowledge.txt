Chapter 01
01
시작하기 전에 — 이 용어들만 알면 충분해요
⚡ 이 챕터 핵심
- VAN사 = 카드사와 가맹점 사이에서 결제를 중계하는 사업자
- 페이앤스토어 = VAN 서비스에 커넥트를 결합해 판매하는 대리점
- 커넥트 = 모든 조합에 반드시 포함되는 필수 구성품
VAN 업계가 처음이신 분들을 위한 최소한의 배경 지식입니다. 딱 4개만 이해하고 넘어가면 됩니다.
업계 구조
VAN이란?
카드사와 가맹점 사이에서 카드 결제를 중계·승인해주는 사업자입니다. 가맹점이 카드결제를 받으려면 반드시 VAN사를 거쳐야 합니다.
우리 회사의 역할
페이앤스토어란?
네이버페이의 오프라인 결제 서비스(Npay 커넥트)를 가맹점에 공급하는 대리점입니다. VAN 서비스에 커넥트라는 상품을 얹어서 판매합니다.
핵심 상품
Npay 커넥트란?
네이버페이가 만든 통합 결제 단말기입니다. 카드·QR·삼성페이 등 모든 결제수단과 포인트·쿠폰·리뷰·미니키오스크 기능까지 한 기기에서 처리합니다. 모든 조합에 반드시 포함되는 필수 구성품입니다.
매장 운영 프로그램
포스(POS)란?
Point Of Sale의 줄임말로, 매장의 메뉴·주문·매출을 관리하는 프로그램입니다. 커넥트가 "결제"를 담당한다면, 포스는 "매장 운영"을 담당합니다.
전체 흐름 한 줄 정리
- 카드사 → VAN사가 결제를 중계 → 페이앤스토어(우리)가 그 VAN 서비스에 커넥트를 결합해서 판매
- 딜러(나)는 페이앤스토어를 대신해 가맹점을 발굴하고 계약까지 이끄는 역할
- 가맹점은 매장 특성에 따라 커넥트 + 포스(필요시) 조합으로 도입
Chapter 02
02
우리가 파는 제품들
⚡ 이 챕터 핵심
- 구성은 3층: 커넥트(필수) + 하드웨어(CAT·태블릿·프린터·금전함) + 포스
- 배달앱 연동은 오케이포스(윈도우)만 가능
- 후불 결제는 페이앤포스 윈도우만 — 안드로이드는 선불 전용
Npay 커넥트 핵심 상품
네이버페이가 선보인 오프라인 통합 단말기입니다.
결제에서 끝나지 않고, 리뷰·포인트·쿠폰까지 하나의 기기에서 모두 처리합니다. 모든 조합에 반드시 포함되는 필수 구성품입니다.
주요 기능
- 모든 결제수단 지원 — 카드·현금·QR·NFC·삼성페이·애플페이 등 고객이 원하는 방식으로 결제
- 포인트 적립 · 쿠폰 — 결제 시 네이버페이 포인트 자동 적립. 보유 쿠폰 즉시 노출·사용 가능
- 현장 리뷰 연동 — 결제 직후 키워드 선택으로 3초 만에 네이버 리뷰 등록. 플레이스 노출 상승 효과
- 미니 키오스크 기능 — 포스 프로그램 연동 시 무인 주문 기능 지원. 1인 운영 매장에서도 활용 가능
- 페이스사인 결제 — 얼굴인식 기반 간편결제
① 결제와 주문을 하나로▾
결제와 주문을 하나로 — 페이스사인·QR/바코드·삼성페이/애플페이·카드까지 한 기기에서 처리
② 결제 한 번으로 손님이 알아서 해요▾
결제 한 번으로 손님이 알아서 — 네이버 로그인·쿠폰 자동 노출·키워드 리뷰·주문/키오스크 전용 모드까지 무인 운영 지원

어떤 매장에 어떤 조합을?
⚡ 이 챕터 핵심
- 핵심 질문 3개: 포스 필요? → 선불/후불? → 배달?
- 답에 따라 조합 A~D가 정해짐 — 아래 시뮬레이터로 연습 가능
- 2026년 7월 기준 SET-07(커넥트+CAT)은 월 0원 프로모션 (3억 이하)
조합 선택 핵심 질문 3가지
① 포스가 필요한 매장인가? ② 선불인가 후불인가? ③ 배달 연동이 필요한가?
이건 딜러가 정하는 것이 아니라, 점주님이 말씀하시는 매장 환경에 맞게 추천을 부탁드려요. 카드마다 있는 대화 예시는 정답이 아니라 참고용 흐름이니 편하게 봐주세요.

조합 선택 흐름도
- 포스가 필요 없는 소규모 매장 → 조합 A (커넥트 + CAT단말기)
- 요식업이고, 배달 없음, 선불 결제 → 조합 B (커넥트 + 페이앤포스 또는 태블릿)
- 요식업이고, 배달 없음, 후불 결제 → 조합 B (커넥트 + 페이앤포스 윈도우) — 안드로이드 버전은 후불 결제 불가
- 요식업이고, 배달 있음 → 조합 C (커넥트 + 오케이포스 윈도우)
- 비요식업 기본 → 조합 D (커넥트 + CAT단말기)
- 뷰티 업종, 예약·고객관리 필요 → 조합 D 확장 (커넥트 + 태블릿 + 페이앤포스 안드로이드)
페이앤포스로 안 되는 상황 → 오케이포스로 전환하면 됩니다.
배달앱 연동은 페이앤포스 윈도우·안드로이드 모두 불가합니다. iOS/Mac, 브랜드앱 연동도 불가이므로 이 경우 오케이포스(윈도우)로 안내해 주세요.

05
영업 프로세스
⚡ 이 챕터 핵심
- 방문 전 네이버 지도로 업종·운영 여부를 먼저 조사
- 신규 매장 vs 기존 매장은 확인 항목이 다름 — 기존은 약정 잔여 필수 확인
- 서류는 아래 체크리스트로 하나씩 확인하며 수취
방문 전 준비
네이버 지도에서 매장명 + 지역 검색으로 미리 파악해 주세요.
업종·운영 여부를 사전에 확인하고 어떤 조합을 제안할지 구상해두면 훨씬 자연스러운 상담이 가능합니다.
- 업종 확인 — 요식업 여부, 홀 운영 or 배달 병행 여부
- 신규 오픈 매장인지, 기존 운영 중인 매장인지 구분
- 기존 매장이면 현재 포스·단말기가 무엇인지 파악 시도
- 제안할 조합 A~D 중 사전에 결정해두기
신규 매장 안내
- 사업자등록증 발급 여부 및 예정일 확인 (개인 / 법인·공동대표 구분)
- 업종 확인 가능한 사진 첨부 여부 확인
- 인터넷 도입 필요 여부 확인
기존 운영 매장 안내
- 기존 장비 정보 확인 — 약정 잔여 개월 수, 월 납부금, 포스 정보
- 사업자번호 확인
- 개인 / 법인 여부 + 공동대표 여부 확인
- 대형가맹점 여부 확인 (연매출 3억 이상 시 커넥트 할인가 적용 불가)
기존 약정이 남아 있는 경우
기존 대리점 약정 잔여 기간 확인이 필수입니다. 약정이 남아 있으면 위약금이 발생할 수 있으니 가맹점주께 반드시 안내해 주세요.
서류 수취 체크리스트
신규 매장
- 사업자등록증 사본
- 업종 확인 가능한 매장 사진
- 개인 / 법인 여부 (공동대표 있을 경우 전원 서명 필요)
- 오픈 예정일
- 포스 구성품 선택 내역
기존 운영 매장 추가 확인
- 기존 포스·단말기 약정 잔여 개월 수
- 기존 장비 모델명 (사진 첨부 권장)
- VAN 전산 유실적 확인 (관리자에게 사업자번호 전달 부탁드립니다)
사업자 유형에 따라 추가로 필요한 서류가 달라질 수 있습니다. 별도로 전달되는 서류 체크리스트를 함께 참고해 주세요.
계약 완료 후
가맹점주 서명 완료 → 페이앤스토어에 인계 → 딜러의 역할 종료
이후 설치·운영·AS는 페이앤스토어 및 기술 파트너가 담당합니다.

06
영업 시 유의사항
⚡ 이 챕터 핵심
- 커넥트+CAT은 기본 자가설치 — 랜선은 점주님이 직접 준비
- 기기 색상(블랙/화이트) 기재 누락은 재발송 비용으로 직결
- 인터넷은 필수 — 포스는 랜선, 커넥트는 와이파이 가능
① 설치 방식 안내▾
커넥트 + CAT단말기 조합은 특수한 상황을 제외하면 점주 자가설치로 진행됩니다.
- 기존에 사용 중인 포스가 있어서 연동이 필요한 경우, 점주 자가설치가 어려워 현장 설치 기사님 방문이 필요합니다.
- 이런 경우 서류 수취 시 "기존 사용중인 포스가 있어서 연동 필요" 여부를 특이사항에 반드시 기재해 주세요.
특이사항 누락 시 기사님 방문 없이 자가설치 건으로 처리되어 설치 지연 및 재조율이 발생합니다.
자가설치를 진행하는 경우, 랜선은 반드시 점주님이 직접 준비하셔야 합니다. 이 부분은 사전에 꼭 안내해 주세요.
② 인터넷 연결 안내▾
커넥트와 포스는 인터넷 연결이 반드시 필요합니다.
인터넷 설치 여부, 그리고 커넥트·포스가 설치될 자리에 랜선이 나와있는지 무조건 확인해 주세요.
- 단말기(포스)는 랜선 연결이 필수입니다.
- 커넥트는 랜선 연결이 어려운 경우 와이파이로 연결 가능합니다.
③ 기기 색상 안내▾
커넥트 · 금전함 · 유선프린터는 블랙 / 화이트 두 가지 색상이 있습니다.
점주님께 색상 옵션을 반드시 안내하고, 서류 수취링크 작성 시 선택한 색상을 정확히 기재해 주세요.
- 색상 오안내 시 커넥트를 두 번 보내야 하는 상황이 반복적으로 발생하고 있습니다.
미준수 시 발생하는 비용 · 업무
왕복 택배비 · 박스비 · 모두싸인 재발송 비용에 더해, 회수된 장비의 검수 및 재포장 작업까지 뒷단에서 추가로 발생합니다. 작은 확인 하나가 뒷단 비용·업무 부담으로 이어지니 꼭 챙겨주세요.
④ 가입 제한 업종▾
모든 조합에 커넥트가 필수로 포함되므로, 커넥트 도입이 불가한 업종은 가입이 제한됩니다.
- 도박
- 유흥업소
제한 업종 목록은 계속 추가될 예정입니다. 업데이트되는 대로 반영하겠습니다.
⑤ 계약서 서명 이탈 예방▾
서류 수취 후, 계약서 서명 전에 이탈하는 경우가 종종 발생합니다.
아래 사유들을 미리 확인·안내해서 서명 전 이탈을 예방해 주세요.
- 단순 변심
- 기존 대리점 계약에 위약금이 남아있는 경우
- 매장 환경 문제 — 예: 유선프린터로 주문했으나 포설이 안 되어 무선프린터로 변경해야 하는데, 이마저 원하지 않는 경우
- 인터넷 연결이 되지 않는 경우
- NICE / KIS 두 밴사 모두 유실적이 있는데, 기존 대리점에서 이중등록에 협조하지 않는 경우
- 치과·학원 등 특정 솔루션과 커넥트의 연동이 필요한 경우

⚡ 이 챕터 핵심
- 현장에서 자주 듣는 거절 7가지 — 상황별 응대 포인트 + 대화 예시
- 스크립트는 정답이 아니라 참고용 — 점주님 상황에 맞게 변형해서 사용
- 확정 안 된 조건(수수료·기간)은 임의로 약속하지 않기
사용 안내 — 아래 스크립트는 정답이 아니라 참고용 흐름입니다. 점주님 상황에 맞게 자연스럽게 변형해서 사용해 주세요. 확정되지 않은 조건(수수료·기간 등)은 임의로 약속하지 말고 반드시 페이앤 담당자 확인 후 안내해 주세요.
💬"이미 쓰는 포스가 있어서 괜찮아요"
응대 포인트 — 교체가 아니라 '추가'라는 프레임
커넥트는 기존 포스를 들어내는 제품이 아니라, 기존 환경에 연동해서 리뷰·포인트·쿠폰 기능을 더하는 제품입니다. 기존 포스 연동이 필요한 경우 서류 수취 시 특이사항에 기재하면 설치 기사님이 방문해 연동해 드립니다.

FAQ
자주 묻는 질문
설치는 누가 하나요? 딜러가 해야 하나요?
아니요. 계약 서명 완료 후 페이앤스토어에 인계하면 딜러의 역할은 종료됩니다. 설치·기술지원·A/S는 페이앤스토어 및 기술 파트너가 전담합니다. 단, 커넥트+CAT 조합은 특수한 경우를 제외하면 점주 자가설치로 진행되며, 기존 포스 연동이 필요한 경우에만 기사님이 방문합니다.
기존 포스가 있는 매장인데 연동 설치가 필요하면 어떻게 하나요?
서류 수취 시 특이사항에 "기존 사용중인 포스가 있어서 연동 필요"를 반드시 기재해 주세요. 누락되면 자가설치 건으로 처리되어 설치 지연과 재조율이 발생합니다.
커넥트는 와이파이로 연결해도 되나요?
커넥트는 랜선 연결이 어려운 경우 와이파이 연결이 가능합니다. 단, 포스(단말기)는 랜선 연결이 필수입니다. 자가설치 시 랜선은 점주님이 직접 준비하셔야 하므로 사전에 꼭 안내해 주세요.
기기 색상은 선택할 수 있나요?
커넥트·금전함·유선프린터는 블랙/화이트 두 가지 색상이 있습니다. 점주님께 색상 옵션을 반드시 안내하고, 서류 수취링크 작성 시 선택한 색상을 정확히 기재해 주세요. 오기재 시 장비 재발송·회수·재포장 비용이 발생합니다.
연매출 3억 이상 매장은 어떻게 다른가요?
대형가맹점(연매출 3억 이상)은 커넥트 할인가 적용이 불가하며, 렌탈 표에서 "3억 이상(중고CMS)" 컬럼 기준이 적용됩니다. 예를 들어 SET-07 0원 프로모션도 3억 이상 매장은 월 990원이 적용됩니다. 기존 매장 상담 시 대형가맹점 여부를 반드시 확인하세요.
공동대표 매장은 서류가 다른가요?
개인/법인 여부와 함께 공동대표 여부를 확인해야 하며, 공동대표가 있는 경우 전원 서명이 필요합니다. 사업자 유형에 따라 추가 서류가 달라질 수 있으니 별도 서류 체크리스트를 함께 참고하세요.
NICE / KIS 이중등록 이슈가 뭔가요?
두 밴사 모두 유실적이 있는 매장에서 기존 대리점이 이중등록에 협조하지 않으면 서명 전 이탈로 이어질 수 있는 케이스입니다. 기존 매장은 VAN 전산 유실적 확인이 필요하니, 관리자에게 사업자번호를 전달해 사전 확인을 요청하세요.
가입이 안 되는 업종이 있나요?
모든 조합에 커넥트가 필수로 포함되므로, 커넥트 도입이 불가한 업종(도박, 유흥업소 등)은 가입이 제한됩니다. 제한 업종 목록은 계속 업데이트될 예정입니다.

02기존 사업자 결정 트리▾
커넥트를 넣으려면 결제(밴)를 우리 쪽으로 가져와야 합니다 — 기존 위에 그냥 얹는 건 안 됩니다. 그래서 계약 관계부터 확인한 뒤 장비를 구성합니다.
커넥트 = 프론트 단말. 기존 매장 장비는 ① 프론트 단말(결제+출력: 토스프론트 등) ② POS 프로그램 하드웨어(오케이포스 등) 두 종류. 커넥트가 프론트 자리를 대체·신설하고, 기존 POS 하드웨어는 유지·연동합니다.
#### 1단계 · 기존 계약 관계부터 확인
무실적/유실적만 보고 바로 진입하지 않습니다. 아래 3가지를 함께 확인합니다.
① 밴 등록이 되는가
현재 KIS · NICE 두 밴사로 운영. 다만 KSNET · KICC는 이미 개설 완료이고 앞으로 밴사를 계속 늘려나갈 예정입니다.
KIS/NICE 중 하나라도 무실적 → 그 밴사로 진입 가능 ✅
둘 다 유실적 → 직접 진입 불가
→ 점주에게 기존 밴 대리점·담당자 정보 받아 이중등록 요청 (수락 → 진행 / 거부 → 종료)
→ 추후 다른 밴사 확장 시 재진입 가능
② 위약금이 남아 있는가
없음 → 바로 전환 유도
있음 → 잔여 금액 확인
(남은 위약금 + 앞으로 낮은 CMS) vs 지금 부담 비교 → 낮은 CMS로 전환 설득 · 위약금은 우리가 대신 내주지 않음
③ 해약하면 장비를 가져가는가
회수 조항 있음 → 포스·프린터 빠짐
→ 그만큼 우리가 새로 공급 (2단계 구성에 반영)
#### 2단계 · 장비 · 프로그램 구성 (무엇이 남는지 정해진 뒤)
- 프론트 자리 → 커넥트가 대체 / 신설
- 남는 POS 하드웨어 → 커넥트와 연동
- 회수돼 빠지는 포스·프린터 → 커넥트 + POS(+프린터/CAT)로 채워 공급
↪ 새로 공급할 POS를 고를 땐 04번 POS 선택 로직을 그대로 재사용합니다.

03공통 설치 관문 — 인터넷 점검▾
솔루션이 정해진 뒤 모든 케이스에 공통으로 붙는 점검입니다. 결과에 따라 준비물·안내만 달라질 뿐, 설치 자체를 무산시키지 않습니다.
- 인터넷 있음 + 랜선이 단말 위치까지 도달 → 그대로 설치
- 인터넷 있으나 랜선 미도달 → 배선 연장 또는 와이파이/공유기 안내 (주방 무선 프린터 시 간섭요소 점검)
- 인터넷 없음 → 점주 가설·신청 안내 → 최악의 경우 페이앤스토어가 인터넷 상담까지 지원
기기별 연결 규칙 — 포스(단말기)는 랜선 연결 필수. 커넥트는 랜선이 어려운 자리라면 와이파이 연결 가능. 설치 자리에 랜선이 나와 있는지 반드시 확인하세요.

키오스크는 세 제품 모두 됩니다. 그래서 "키오스크만" 요구로는 POS가 안 좁혀지고, 공간·보유기기·취향이 결정합니다. 반대로 배달 매출연동·태블릿오더는 오케이포스, 네이버 예약은 페이앤 안드로이드로 강제됩니다.
#### STEP 1 · 기능 요건 필터
- 배달 매출연동→오케이포스(윈도우) + 배달매니저 확정

- 네이버 예약→페이앤 안드로이드 단독
- 후불 결제→페이앤 윈도우 / 오케이포스 (안드로이드 탈락)
- CRM 중시→페이앤 안드로이드 우세
- 배달 위젯·네이버 주문·큐알·키오스크→여러 제품 가능 → STEP 2에서 확정
충돌 규칙 — 요건들이 서로 다른 POS를 강제해 한 대로 불가하면(예: 배달 매출연동 + 네이버 예약) → 점주가 우선순위 기능 하나를 선택해 그 POS로 확정합니다.
#### STEP 2 · 물리 · 보유기기 · 취향 필터
- 카운터 협소→PC포스 불가 → 안드로이드 태블릿

- 단순 취향→윈도우 / 안드로이드 선택

06표준 상담 체크리스트▾
상담 한 번에 트리를 끝까지 태우는 데 필요한 정보를 빠짐없이 수집합니다.
#### A. 공통 (모든 매장)
- 신규 오픈 / 기존 운영 구분
- 업종 — 음식점 여부
- 필요 기능 — 배달(위젯/매출연동), 후불, 태블릿오더, 큐알오더, 키오스크, 네이버 주문/예약, CRM
- (음식점) 주방 주문서 출력 / 추가 주문포스 필요 여부
- 인터넷 설치 여부 → 랜선이 단말 위치까지 도달 → 안 되면 와이파이 가능 여부
- 점주 보유기기(예: 아이패드) / 카운터 공간 협소 여부
- 기기 색상 — 블랙 / 화이트
- 개인 / 법인 / 공동대표 여부
#### B. 기존 매장 추가 확인
- 현재 결제 환경 — 프론트(토스 등) / POS 프로그램 하드웨어 종류
- 밴 유·무실적 — 사업자번호를 관리자에게 전달해 사전 조회
- 위약금·약정 — 잔여 개월 수, 월 납부금
- 기존 장비 소유 — 매장 소유 / 대리점 임대 + 해약 시 회수 조항 여부
- 대형가맹점 여부 — 연매출 3억 이상(커넥트 할인가 적용 불가)
- 특이사항 — 기존 포스 연동 필요 여부(→ 설치 기사 방문 대상)
07영업 불가 · 예외 케이스▾
"될 것 같지만 구조적으로 안 되는" 상황입니다. 합법적으로 사업자등록·인허가를 갖춘 업종은 카드 가맹이 대부분 가능하며(유흥업소도 정상 카드가맹이 되면 진행 가능), 카드 가맹 자체가 불가한 경우만 영업 불가입니다.
#### ① 카드 가맹 불가
- 불법·무허가 영업 (사업자등록·인허가 없는 업종)
- 불법 사행행위 — 불법 도박장, 사설 경마·경륜·스포츠토토, 불법 카지노
- 성매매 등 불법 성인 영업 (합법 유흥·단란주점은 제외 — 가능)
- 마약·대마 등 금지 물품 거래
- 무허가 총포·도검·화약
- 유사수신·불법 다단계·불법 대부업
- 기타 관계법령상 거래가 금지된 재화·용역
⚠ 카드사·밴사별 심사 기준이 조금씩 다릅니다. 애매한 업종은 밴사·카드사에 개별 확인 후 진행하세요. (온라인 PG 불가 목록과 혼동 금지 — 그건 비대면 기준)
#### ② 밴 등록 불가
KIS·NICE 두 밴사 모두 유실적 + 기존 대리점이 이중등록 거부 → 진입 불가. (밴사 확장 예정이므로 추후 재시도 가능)
#### ③ 인터넷 불가
인터넷 없음/도입 거부, 또는 랜선 미포설로 무선 전환이 필요한데 점주가 거부 → 설치 불가.
#### ④ 특정 솔루션 연동 필요
치과·학원 등 특정 솔루션과 커넥트 연동이 필요한 경우 → 별도 확인 후 진행.
08서명 전 이탈 예방▾
될 수 있는데 놓쳐서 새는 케이스입니다. 서류 수취 후 서명 전에 이탈하는 아래 사유들을 미리 확인·안내해 예방하세요.
- 단순 변심
- 기존 대리점 계약에 위약금이 남아 있는 경우 (투명 안내 + 만료 시점 재방문 약속)
- 매장 환경 문제 — 유선프린터 주문했으나 포설이 안 돼 무선으로 바꿔야 하는데 이를 원치 않는 경우
- 인터넷 연결이 되지 않는 경우
- NICE / KIS 두 밴사 모두 유실적인데 기존 대리점이 이중등록에 협조하지 않는 경우
- 치과·학원 등 특정 솔루션과 커넥트 연동이 필요한 경우
09처리 절차 · 기간▾
접수부터 설치까지 전체 흐름과 딜러 역할이 끝나는 지점입니다.
상담·사전 조사 — 방문 전 네이버 지도로 업종·운영 여부 파악 → 상담 체크리스트로 확인
서류 수취 — 서류 수취 링크로 접수 (기존 매장은 밴 유실적 확인 병행)

계약서 서명 → 페이앤스토어 인계 → 여기서 딜러 역할 종료
개설 / 이관 처리 — 페이앤스토어 진행
설치 — 커넥트+CAT 자가설치 / 기존 포스 연동 시 설치 기사 방문

소요 기간 — 영업일 기준 2~3일. 단, 서류에 오류가 없고 점주님이 바로 서명한다는 가정 하의 기준입니다.
10영업 후 설치까지 유의사항▾
#### ① 설치 방식
커넥트 + CAT단말기는 특수 상황을 제외하면 점주 자가설치로 진행됩니다.
- 기존 포스 연동이 필요하면 현장 설치 기사 방문 → 서류 수취 시 "기존 포스 연동 필요"를 특이사항에 반드시 기재
- 자가설치 시 랜선은 점주가 직접 준비
특이사항 누락 시 자가설치 건으로 처리되어 설치 지연·재조율이 발생합니다.
#### ② 기기 색상
커넥트·금전함·유선프린터는 블랙 / 화이트 두 가지. 서류 수취링크 작성 시 선택 색상을 정확히 기재하세요.
색상 오안내 시 왕복 택배비·박스비·모두싸인 재발송 + 회수 장비 검수·재포장까지 뒷단 비용이 발생합니다.
※ 인터넷·랜선·와이파이 유의점은 03번 공통 설치 관문에 정리돼 있습니다. 서류는 별도 서류 체크리스트를 함께 참고하세요.

12거절 응대 스크립트▾
사용 안내 — 아래 스크립트는 정답이 아니라 참고용 흐름입니다. 점주님 상황에 맞게 변형해 사용하고, 확정되지 않은 조건(수수료·기간)은 임의로 약속하지 말고 담당자 확인 후 안내하세요.
💬 "이미 쓰는 포스가 있어서 괜찮아요"
교체가 아니라 '연동 + 결제 전환' 프레임
기존 포스(주문·매출관리)는 그대로 두고 연동합니다. 다만 결제는 커넥트로 옮겨와, 리뷰·포인트·쿠폰이 결제와 함께 자동으로 돌아갑니다. 기존 포스 연동이 필요하면 서류 수취 시 특이사항에 기재하면 설치 기사님이 방문해 연동해 드립니다.
SCRIPT"지금 쓰시는 포스는 그대로 두시면 돼요. 결제만 커넥트로 옮겨오시면 네이버 리뷰랑 포인트 적립이 자동으로 같이 돌아갑니다."
💬 "기존 계약 위약금이 남아있어요"
잔여 개월 확인 먼저, 무리한 해지 유도 금지
기존 대리점 약정 잔여 개월을 먼저 확인합니다. 위약금 발생 가능성은 반드시 투명하게 안내하고, 남은 위약금과 앞으로의 낮은 CMS를 비교해 설득합니다. 잔여 기간이 짧으면 만료 시점 재방문 약속도 방법입니다.
SCRIPT"지금 계약이 몇 개월 남으셨을까요? 위약금이 나오면 무리하게 바꾸시라곤 안 해요. 다만 남은 위약금이랑 저희 낮은 수수료를 같이 계산해보면 오히려 이득인 경우가 많아서, 한번 비교해 드릴게요."
💬 "월 비용이 부담돼요"
0원 프로모션 세트와 저비용 구성 제시
2026년 7월 기준 커넥트+CAT단말기(SET-07)는 월 0원 프로모션(연매출 3억 이하). 포스가 필요하면 태블릿 구성으로 비용을 낮출 수 있습니다. 가격은 시점별 변동되니 항상 최신 가격표로 안내하세요.
SCRIPT"결제만 필요하시면 지금 프로모션으로 월 비용 없이 시작하실 수 있어요. 부담 없이 써보시고 나중에 포스를 붙이셔도 됩니다."
💬 "네이버 리뷰까지는 필요 없어요"

💬 "매장에 인터넷이 없어요"

커넥트·포스는 인터넷 연결이 필수입니다. 없는 매장은 도입 필요 여부를 서류 수취 단계에서 확인해야 하며, 필요 시 페이앤스토어가 인터넷 상담을 지원합니다. 커넥트는 와이파이 가능하지만 포스는 랜선이 필수입니다.

설치는 누가 하나요? 딜러가 해야 하나요?▾아니요. 계약 서명 완료 후 페이앤스토어에 인계하면 딜러 역할은 종료됩니다. 설치·기술지원·A/S는 페이앤스토어 및 기술 파트너가 전담합니다. 커넥트+CAT 조합은 특수한 경우를 제외하면 점주 자가설치이며, 기존 포스 연동이 필요한 경우에만 기사님이 방문합니다.
기존 포스가 있는데 연동 설치가 필요하면?▾서류 수취 시 특이사항에 "기존 사용중인 포스가 있어서 연동 필요"를 반드시 기재하세요. 누락되면 자가설치 건으로 처리되어 설치 지연·재조율이 발생합니다.
커넥트는 와이파이로 연결해도 되나요?▾커넥트는 랜선 연결이 어려운 경우 와이파이 가능합니다. 단, 포스(단말기)는 랜선 연결이 필수입니다. 자가설치 시 랜선은 점주님이 직접 준비하셔야 하니 사전에 안내하세요.
기기 색상은 선택할 수 있나요?▾커넥트·금전함·유선프린터는 블랙/화이트 두 가지입니다. 서류 수취링크 작성 시 선택 색상을 정확히 기재하세요. 오기재 시 장비 재발송·회수·재포장 비용이 발생합니다.
연매출 3억 이상 매장은 어떻게 다른가요?▾대형가맹점(연매출 3억 이상)은 커넥트 할인가 적용이 불가하며, 렌탈표에서 "3억 이상(중고CMS)" 컬럼이 적용됩니다. SET-07 0원 프로모션도 3억 이상은 월 990원입니다. 기존 매장 상담 시 대형가맹점 여부를 반드시 확인하세요.
공동대표 매장은 서류가 다른가요?▾개인/법인 여부와 함께 공동대표 여부를 확인해야 하며, 공동대표가 있으면 전원 서명이 필요합니다. 사업자 유형에 따라 추가 서류가 달라질 수 있으니 별도 서류 체크리스트를 참고하세요.
NICE / KIS 이중등록 이슈가 뭔가요?▾두 밴사 모두 유실적인 매장에서 기존 대리점이 이중등록에 협조하지 않으면 서명 전 이탈로 이어질 수 있습니다. 기존 매장은 VAN 유실적 확인이 필요하니 관리자에게 사업자번호를 전달해 사전 확인을 요청하세요. 밴사는 계속 확장 예정이라 추후 다른 밴사로 진입할 수도 있습니다.
가입이 안 되는 업종이 있나요?▾합법적으로 사업자등록·인허가를 갖춘 업종은 카드 가맹이 대부분 가능합니다(유흥업소도 정상 카드가맹이 되면 진행 가능). 불법·무허가 영업, 불법 사행행위(불법 도박 등), 성매매 등 불법 성인영업, 마약, 무허가 총포, 유사수신·불법 다단계·불법 대부 등 카드 가맹 자체가 불가한 업종만 제한됩니다. 애매하면 밴사·카드사에 개별 확인하세요.

# 신규 사업자 결정 트리
매장 영업 첫 단계 — 신규 사업자 대상 장비·POS 통합 결정 로직 / 방향 확인용 맛보기
📩
고객사 확인 요청. 아래는 신규 사업자 상담 흐름을 트리로 정리한 초안입니다. 실제 CS에서 이 순서·분기·솔루션이 현장과 맞는지 검토 부탁드립니다. 확정되면 같은 방식으로 기존 사업자(오케이·토스 조합별 전환) 가지까지 붙여 완성본으로 이어갑니다.
Overview
## 전체 구조 — 결정은 2층으로 나뉩니다
먼저 무엇을 드릴지(솔루션)를 정하고, 그 뒤 모든 케이스에 설치가 가능한지(환경)를 공통으로 점검합니다. 인터넷 문제는 솔루션을 바꾸지 않으므로 분기가 아니라 공통 관문입니다.
LAYER 1 · 솔루션 결정
### 무엇을 드릴지
업종 → 필요 기능으로 장비 구성과 POS를 함께 확정. 커넥트는 모든 구성에 필수 포함.
LAYER 2 · 설치 관문
### 어떻게 설치할지
인터넷·랜선·와이파이 점검. 준비물(공유기·배선)만 달라질 뿐 설치를 막지 않음 — 최악의 경우 페이앤스토어가 인터넷 상담까지 지원.
Layer 1 · Tree
## 신규 사업자 결정 트리
첫 질문은 업종. 여기서 갈린 뒤, 필요 기능에 따라 장비가 쌓이고 POS가 정해집니다. POS 선택 자체는 아래 2단계 깔때기를 따릅니다.
🟢 Npay 커넥트 — 모든 구성에 필수 포함
Q1 업종이 무엇인가요?
분기 · 비음식점 (소매 · 서비스 · 뷰티)
Q POS(주문·매출관리)가 필요한가요?
아니오
RESULT커넥트 + CAT단말기 (단순 카드결제)
예
→ POS 선택 로직예약·고객관리 중심(뷰티 등)이면 → 커넥트 + 태블릿 + 페이앤 안드로이드
분기 · 음식점
기본 골격: 커넥트 + POS ( + CAT단말기 )
→ POS는 POS 선택 로직으로 확정
Q 주방 주문서 출력이 필요한가요?
예 → + 주방 프린터
랜선이 주방까지 도달 → 유선 프린터
랜선 미도달 → 무선 프린터 + 무선환경 간섭요소 점검

## POS 선택 로직 — 2단계 깔때기
장비와 POS는 분리할 수 없습니다. 필요 기능이 후보를 좁히고(1단계), 남은 후보를 물리·보유기기·취향으로 확정합니다(2단계).
STEP 1 · 기능 요건 필터
### 필요 기능이 POS를 강제하거나 탈락시킵니다
- 배달 매출연동→오케이포스(윈도우) + 배달매니저 확정
- 물리 테이블오더→오케이포스(윈도우)
- 네이버 예약→페이앤 안드로이드 단독
- 후불 결제→페이앤 윈도우 / 오케이포스 (안드로이드 탈락)
- CRM 중시→페이앤 안드로이드 우세
- 배달 위젯 · 네이버 주문 · 큐알 · 키오스크→여러 제품 가능 → 2단계에서 확정
⚠ 충돌 규칙. 요건들이 서로 다른 POS를 강제해 한 대로 불가하면(예: 배달 매출연동 + 네이버 예약) → 점주가 우선순위 기능 하나를 선택 → 그 POS로 확정합니다.
STEP 2 · 물리 · 보유기기 · 취향 필터
### 1단계 후보가 복수일 때 최종 확정
- 카운터 협소→PC포스 불가 → 안드로이드 태블릿
- 보유기기 아이패드→iOS라 우리 앱 불가 → 사용 불가 안내
- 단순 취향→윈도우 / 안드로이드 선택
Layer 2 · Gate
## 설치 관문 — 인터넷 점검 (모든 잎 공통)
솔루션이 정해진 뒤 붙는 공통 체크리스트입니다. 결과에 따라 준비물과 안내만 달라질 뿐, 설치 자체를 무산시키지 않습니다.
- 인터넷 있음 + 랜선이 단말 위치까지 도달 → 그대로 설치
- 인터넷 있으나 랜선 미도달 → 배선 연장 또는 와이파이/공유기 안내 (주방 무선 프린터 시 간섭요소 점검)
- 인터넷 없음 → 점주 가설·신청 안내 → 최악의 경우 페이앤스토어가 인터넷 상담까지 지원
