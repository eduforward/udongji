우동지 CRM 사용법

네이버페이 커넥트 상담부터 배송 완료까지, 구성원이 매일 쓰는 화면을 순서대로 정리했어요.

상담 업무→작성 완료→계약 업무 (서류 → 이관 → 서명 → 배송)→고객 목록에서 조회·수정

시작하기

로그인과 홈 화면
1

구글 계정으로 로그인

홈에서 구글 계정으로 로그인을 누르세요. 관리자가 등록한 계정만 열리고, 상담자 이름은 관리자가 등록한 이름으로 자동 고정돼요 (본인이 바꿀 수 없음).

2

홈의 업무 카드

상담 업무·재연락·계약 업무·고객 목록 네 카드에 나의 오늘 건수, 진행 중 건수, 서류 대기 같은 집계가 실시간으로 떠요. 상단 메뉴와 아이콘이 같으니 어디서든 같은 모양을 찾으면 됩니다.

3

버전 배지

상단 오른쪽 v43 · 날짜 배지를 누르면 최근 업데이트 내역이 뜨고, 화면이 옛 버전으로 보이면 자동으로 새로고침돼요.

상담 업무

스크립트 보면서 통화하고 바로 기록

화면 자체가 상담 대본이에요. 상담원 말풍선을 읽으며 진행하고, 중간중간 나오는 빨간 입력칸에 답을 적으면 그대로 고객 기록이 됩니다. 입력은 자동 저장되니 브라우저를 닫아도 남아요.

1

기본정보 먼저

통화 시작하며 고객명·연락처·매장명·매장 주소를 적어요. 연락처는 숫자만 쳐도 하이픈이 자동으로 들어가요 (010-0000-0000, 02-123-2020). 매장명 옆 지도는 매장명으로 네이버 지도를 열어줘요.

2

매장 구분 선택

신규 오픈 / 기존 운영을 고르면 아래 단계가 그에 맞게 열려요. 기존 운영은 밴 조회를 위해 동의·사업자번호를 먼저 받고, 신규 오픈은 구성 안내 뒤에 동의를 받아요.

3

단계대로 진행

사전 확인(업종·인터넷 회선) → 구성 잡기(POS·요금) → 설치 관문(색상·특이사항) → 동의 → 서류 안내 → 우동지 솔루션·수신 동의 → 마무리. 하단 바에 필수 항목 남은 개수가 표시돼요.

동의 문장은 유선 녹취가 원칙 — "네, 동의합니다"를 받은 뒤 O를 체크하세요.

4

작성 완료

필수 항목이 다 채워지면 하단 작성 완료가 활성화돼요. 누르면 서버에 저장되고 작성 완료 화면으로 넘어가 고객 안내 문자·페이앤 관리자 접수 양식을 복사할 수 있어요. 폼은 다음 상담을 위해 비워집니다.

5

중간에 끊겼다면 — 일시 종료

고객이 바쁘거나 거절하면 하단 일시 종료. 상담 연기(재연락 시기 지정 또는 미정 → 재연락 목록으로) 또는 상담 거부를 고르고 메모를 남기세요. 고객명·연락처만 있으면 종료할 수 있어요.

주의새 상담은 입력 중인 내용을 모두 지워요. 작성 완료를 안 했으면 저장되지 않으니 먼저 완료하거나 일시 종료하세요.

재연락

상담 연기·재연락 예정 고객을 약속 날짜순으로

일시 종료에서 "상담 연기"로 저장한 고객이 모여요. 홈 카드의 오늘까지 N건이 오늘 안에 연락해야 할 건수예요.

1

필터로 찾기

오늘까지 / 전체 / 내 담당 세 필터와 검색(매장명·고객명·연락처)으로 골라요. 지난 약속은 빨간 표시.

2

이어서 상담

이어서 상담 →을 누르면 상담 업무 화면이 이전 기록을 불러온 상태로 열려요. 이어서 채우고 작성 완료하면 새 기록이 아니라 같은 고객 기록이 갱신되고, 재연락 횟수가 올라가요.

3

문자 · 일정 변경 · 종료

재연락 문자는 고객명·상담자 이름이 들어간 문자를 복사해요. 일정 변경은 다음 연락 일시와 메모를 바꾸고, 종료는 더 연락하지 않는 고객으로 처리해 목록에서 빼요.

계약 업무

상담 후 고객별 4단계 추적

"상담 진행"으로 작성 완료된 고객이 자동으로 표에 들어와요. 행을 클릭하면 오른쪽 서랍이 열립니다.

수취자료→페이앤 이관→전자서명 완료→커넥트 배송 완료
1

수취자료 — 서류 받기

매장 구분·법인·공동대표 여부에 따라 필요한 서류 목록이 자동으로 뜨고, 고객이 카톡으로 보낸 사진을 업로드하면 자동으로 받음 체크되고 매장명_고객명_서류명_순번.jpg로 저장소에 정리돼요 (PDF·PNG는 JPG로 변환). 다 받았으면 수취 완료 처리. 덜 받았으면 서류 재촉 문자 복사로 못 받은 서류 목록이 담긴 문자를 보내세요.

2

페이앤 이관

페이앤 관리자 전달 양식을 복사해 페이앤 관리자에게 보내고, 고객 안내 문자를 고객에게 보낸 뒤 페이앤 이관 완료 처리.

3

전자서명 · 배송

고객이 전자서명을 마치면 전자서명 완료 처리, 커넥트 기기가 배송되면 커넥트 배송 완료 처리. 배송 완료 시 고객이 수신 동의했다면 30일 뉴스레터가 자동 등록돼요.

4

진행 메모

재촉 연락·특이사항은 진행 메모에 적어두면 표에서도 보이고 다른 구성원과 공유돼요.

표 필터

진행 중 · 서류 대기 · 수령 완료 · 전체. 상단 저장소 열기로 서류 폴더를 바로 열 수 있어요.

단계 되돌리기

서랍의 단계 칩을 클릭하면 완료(오늘 날짜) ↔ 취소가 토글돼요. 잘못 눌렀으면 다시 클릭.

참고페이앤에서 배송 이후 설치 여부는 알려주지 않아요. 마지막 단계는 배송 완료까지만 추적합니다.

고객 목록

전체 상담 기록 조회·수정·삭제

모든 상담 기록을 표로 봐요. 매장명·고객명·연락처·사업자번호·업종으로 검색하고, 열 머리글을 눌러 정렬, 상단 필터로 매장 구분·상담자별로 좁힐 수 있어요.

1

상세 보기

행을 클릭하면 서랍에 기본정보·사업자·구성·계약 진행 상태가 그룹별로 뜨고, 값 옆 복사로 하나씩 복사할 수 있어요. 받은 서류는 보기 N으로 바로 열려요.

2

수정

수정을 누르면 항목이 입력칸으로 바뀌어요. 바꾼 뒤 저장 — 바뀐 항목만 서버에 반영돼요. 상담자 이름은 관리자만 바꿀 수 있어요. Esc로 취소.

3

삭제

삭제하면 목록에서 사라지지만 원본·삭제한 사람·시간이 관리자 삭제 로그에 영구 보관돼요. 실수했으면 관리자에게 복구를 요청하세요.

상담시간 설정

관리자 전용 · 홈페이지 전화·채팅 버튼 운영 시간

우동지 홈페이지의 상담 버튼이 "상담 가능 / 잠시 중단"으로 바뀌는 기준을 여기서 정해요. 저장하면 1분 안에 홈페이지에 반영됩니다.

1

요일별 시간

요일마다 켜고 끄고, 시작·종료 시간을 정해요. 기본은 평일 13:00–21:00, 주말 휴무.

2

휴무일

공휴일·휴가처럼 특정 날짜를 추가하면 그날은 요일 설정과 무관하게 중단으로 표시돼요.

3

즉시 중단 스위치

갑자기 자리를 비울 때 즉시 중단을 켜면 시간표를 무시하고 바로 "잠시 상담 중단"으로 바뀌어요. 돌아오면 끄기만 하면 됩니다.

권한구성원 계정에는 이 메뉴가 보이지 않아요. 관리자·슈퍼관리자만 수정할 수 있고, 저장 후 상단 상태 배지로 지금 상담 가능 상태를 확인하세요.

자주 묻는 질문

상담 중 브라우저가 꺼졌어요.

상담 업무를 다시 열면 "이전 상담 내용 불러왔어요"와 함께 입력한 내용이 그대로 있어요. 작성 완료만 하면 됩니다.

같은 고객이 두 번 등록됐어요.

재연락 고객은 재연락 목록의 이어서 상담으로 열어야 같은 기록이 갱신돼요. 새로 상담 업무를 열어 적으면 새 기록이 생겨요. 중복은 고객 목록에서 하나를 삭제하세요.

계약 업무 표에 고객이 안 보여요.

"상담 진행"으로 작성 완료된 고객만 들어와요. 상담 연기·거부·보류 상태는 재연락이나 고객 목록에서 확인하세요. 배송 완료된 고객은 수령 완료 필터에 있어요.

상담자 이름이 비어 있거나 다른 이름이에요.

상담자는 관리자가 계정에 등록한 이름으로 고정돼요. 관리자에게 이름 등록·수정을 요청하세요.

화면이 옛 버전으로 보여요.

상단 버전 배지 숫자가 최신인지 확인하고, 다르면 새로고침(Ctrl+Shift+R)하세요. 보통은 자동으로 갱신돼요.
