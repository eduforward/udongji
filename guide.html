우동지 CRM 사용법

네이버페이 커넥트 상담부터 배송 완료까지, 구성원이 매일 쓰는 화면을 순서대로 정리했어요.

상담 업무→계약 업무 (수취자료 → 기본정보 → 페이앤 이관 → 전자서명 → 배송)→KPI

시작하기

로그인과 홈 화면
1

구글 계정으로 로그인

홈에서 구글 계정으로 로그인. 관리자가 등록한 계정만 열리고, 상담자 이름은 관리자가 등록한 이름으로 고정돼요 (본인이 바꿀 수 없음). 이름이 등록되지 않은 구성원은 고객이 하나도 안 보이니 먼저 관리자에게 이름 등록을 요청하세요.

2

홈의 업무 카드

상담 업무·재연락·계약 업무·고객 목록·KPI 카드에 나의 오늘 건수, 나의 진행 중, 나의 서류 대기가 떠요. 구성원은 본인이 상담한 고객만 보이고, 관리자는 전체 건수도 함께 표시됩니다.

3

이관 요청

다른 상담자가 고객을 넘겨주면 홈 하단에 이관 요청 N건 카드가 떠요. 건별 수락/거절 또는 전부 수락. 수락해야 상담자가 바뀌고 고객 상세에 이관 이력이 남아요.

4

버전 배지

상단 오른쪽 v79 · 날짜 배지를 누르면 최근 업데이트 내역이 뜨고, 옛 버전이면 자동으로 새로고침돼요. 상단 메뉴바는 스크롤해도 고정입니다.

상담 업무

스크립트 보면서 통화하고 바로 기록

화면 자체가 상담 대본이에요. 상담사 말풍선을 읽으며 진행하고, 중간중간 나오는 입력칸에 답을 적으면 그대로 고객 기록이 됩니다. 입력은 자동 저장되니 브라우저를 닫아도 남아요. 오른쪽 패널에 확정 유형·구성·판매품목·네이버 ID와 고객 안내 문자가 실시간으로 만들어져요.

0

유입 경로

Call-In(전화 문의) / Chat-In(채팅 문의) / Out(접수 고객에게 우리가 전화). 경로에 따라 인사말이 바뀌어요.

1

인사 → 궁금한 점 → 접수 동의

"안녕하세요, 우동지 상담사 ○○○입니다. … 통화 품질을 위해 녹음됩니다. 접수 도와드리기 전에, 먼저 궁금하신 부분 있으실까요?" 로 시작해 질문에 편하게 답하고(FAQ 참고), 필요하면 우동지를 짧게 소개한 뒤 고객이 접수 쪽으로 기울면 "그럼 접수 도와드려도 될까요?" — 동의하면 접수 시작.

Out은 지도로 매장을 봐두고 "○○ 하시는 매장 맞으시죠?"로 확인만, Call-In·Chat-In은 매장 이름·업종을 직접 물어요. 고객명·연락처·매장명(옆 지도로 네이버 지도)·업종·매장 외부 간판 있음/없음을 적어요.

2

유형 판별 (질문 3개)

운영 중/오픈 준비 → 개인/법인 → 단독/공동대표. 여기서 8유형이 확정돼 필요한 서류 목록과 페이앤 접수창이 자동으로 정해져요. 연매출 3억 이상이면 중고 단말기 990원 고지.

3

신규 오픈만 — 사업자등록증

발급 전이면 여기서 멈추고 재연락으로. 오픈 3일 이내면 경고가 떠요.

4

환경 — 포스·랜선·와이파이

현재 포스, 약정, 랜선(있음/없음/모름/인터넷 없음), 와이파이(가능/불가/모름). "모름"은 확인 요령 말풍선이 뜨고 고객 문자에 확인 요청이 붙어요.

5

구성 · 색상 · 판매품목 · 네이버 ID

구성은 커넥트 + 카드단말기(기본, 월 0원, 택배 자가 설치) / 커넥트 + POS(유일하게 설치기사 방문) / 커넥트만. 색상 화이트·블랙, 판매품목(기타면 직접 입력), 네이버 ID — 이메일은 아이디@naver.com으로 자동.

6

서류 안내

유형에 맞는 서류 목록이 자동으로 떠요. 오른쪽 고객 안내 문자를 복사해 보내면 서류 목록·촬영 요령(간판 유무별 매장사진 4~5컷)이 들어가요.

7

마무리 — 하단 바

항목은 권장이고 고객명·연락처만 필수. 계약 업무로 →는 고객명·연락처만 있으면 눌러요 (권장 미입력이 있으면 확인창, 나중에 계약 업무 기본정보에서 보완). 재연락은 "내일 오후 2시", "다음주 월", "9/20"처럼 말로 적으면 날짜로 자동 인식. 고객 포기는 종료 처리. 새 상담은 입력 중인 내용을 지워요.

주의페이앤 접수 링크 번호는 화면에 안 보여요 — 계약 업무 → 페이앤 이관 탭의 페이앤 접수창 열기가 유형에 맞게 알아서 열어줍니다.

재연락

상담 연기·재연락 예정 고객을 약속 날짜순으로

상담 업무에서 "재연락"으로 저장한 고객이 모여요. 기본은 내 담당이고 관리자는 모든 상담자로 전환할 수 있어요.

1

필터로 찾기

오늘까지 / 전체와 검색(매장명·고객명·연락처). 지난 약속은 빨간 표시.

2

이어서 상담

이어서 상담 →을 누르면 상담 업무가 이전 기록을 불러온 상태로 열려요. 이어서 채우고 계약 업무로 넘기면 같은 고객 기록이 갱신되고 재연락 횟수가 올라가요.

3

문자 · 일정 변경 · 종료

재연락 문자 복사, 일정 변경, 종료(더 연락하지 않음 → 포기 상태).

계약 업무

상담 후 고객별 5단계 추적 · 마감 담당은 "마감 업무"

"계약 업무로" 넘긴 고객이 자동으로 표에 들어와요. 행을 클릭하면 오른쪽 서랍이 단계별 탭으로 열립니다. 기본은 내 담당, 관리자는 모든 상담자 전환.

수취자료→기본정보→페이앤 이관→전자서명→커넥트 배송
1

수취자료 — 서류 받기

유형별 서류 목록이 필수/해당 시로 뜨고, 매장사진은 간판 있음 4컷 / 없음 5컷이 한 장씩 칸으로 나뉘어요. 고객이 카톡으로 보낸 사진을 업로드하면 받음 체크·썸네일이 바로 보이고 매장명_고객명_서류명.jpg로 저장소에 정리돼요. 체크를 풀거나 ×로 지우면 파일도 함께 삭제. 다 받았으면 수취 완료 처리, 덜 받았으면 서류 재촉 문자 복사.

2

기본정보 — 페이앤 접수값 입력

사업자번호·주소·법인번호·계좌 등 접수에 들어갈 값을 입력·저장하고 기본정보 완료 처리. 상담에서 비워둔 권장 항목도 여기서 채워요. 여기까지 끝나야 마감 담당 목록에 나타납니다.

3

페이앤 이관

상단 고정 바의 페이앤 접수창 열기 ↗가 고객 유형에 맞는 접수창을 새 탭으로 열어요. 값은 칸별 복사·순서대로 복사로 붙이고, 하단 서류 사진에서 필요한 사진을 체크해 선택한 N장 다운로드 → 페이앤 파일 칸에 첨부. 끝나면 이관 완료 처리.

4

전자서명 · 커넥트 배송

모두싸인 알림톡으로 서명이 오면 전자서명 완료 처리(공동대표는 두 분 모두), 기기가 배송되면 커넥트 배송 완료 처리. 각 탭에 고객 안내 문자가 준비돼 있어요.

5

진행 메모

입력 멈추고 1초 뒤 자동 저장돼요(배지로 상태 표시). 표와 다른 구성원에게도 보여요.

단계 되돌리기

서랍의 단계 칩을 클릭하면 완료(오늘 날짜) ↔ 취소가 토글돼요.

진행 상태

단계에 따라 자동 판정: 수취자료진행 → 기본정보진행 → 페이앤진행 → 전자서명진행 → 커넥트진행 → 완료 (재연락 / 포기는 별도).

참고페이앤은 배송 이후 설치 여부를 알려주지 않아요. 마지막 단계는 배송 완료까지만 추적합니다.

고객 목록

전체 상담 기록 조회·수정·삭제·이관

상담 기록을 표로 봐요. 검색·정렬·상담자/구분 필터, 상단 필터는 전체 · 재연락 · 진행 중 · 완료 · 포기. 건수는 필터를 따라가요.

1

상세 보기 · 수정

행을 클릭하면 서랍에 그룹별 정보와 진행 상태가 뜨고 값 옆 복사. 수정 → 바꾼 뒤 저장. 상담자 이름은 관리자만 변경.

2

이관

상세의 이관(개별) 또는 상단 목록 전체 이관(지금 필터된 목록)으로 받을 사람을 골라 요청 → 상대가 홈에서 수락해야 상담자가 바뀌어요. 보낸 요청은 홈에서 취소 가능.

3

삭제

삭제하면 사유를 남기고, 원본·삭제한 사람·시간이 관리자 삭제 로그에 영구 보관돼요. 실수면 관리자에게 복구 요청.

KPI 대시보드

상담자별 단계 전환율

신규 고객 → 수취자료·기본정보 → 페이앤 이관 → 전자서명 → 커넥트 배송, 5단계 깔때기를 상담자별로 봐요. 기본은 신규 고객 대비 전환율, 이번 달 기준.

1

필터

기간(오늘/이번 주/이번 달/지난 달/전체/직접), 유입 경로, 전환율 기준(신규 대비 / 직전 단계 대비), 지연 기준 일수. 관리자는 내 담당 / 모든 상담자 전환.

2

2단계는 둘 다 완료해야

수취자료·기본정보는 수취 완료일과 기본정보 완료일이 둘 다 찍혀야 도달로 세고, 도달일은 늦은 쪽이에요.

3

지연 · 드릴다운

지연 기준(기본 5일) 넘게 멈춘 고객은 빨갛게 표시. 표의 숫자를 클릭하면 해당 상담자·단계 고객 목록이 아래에 열리고, 클릭하면 계약 업무로 이동해요.

역할 · 권한

관리자 > 계정 관리에서 지정

상담 담당 · 구성원(영업)

본인이 상담한 고객만 조회·처리. 상담 업무·재연락·계약 업무·고객 목록·KPI 사용.

마감 담당

기본정보까지 완료된 고객만 보여요. 홈에 마감 업무 카드 하나 — 페이앤 이관 → 전자서명 → 배송 완료를 처리.

관리자

모든 고객 조회, 내 담당/모든 상담자 전환, 계정·이름 관리, 삭제 로그, 상담시간, 엑셀용 복사.

슈퍼관리자

관리자 지정 권한까지.

상담시간 설정

관리자 전용 · 홈페이지 전화·채팅 버튼 운영 시간

우동지 홈페이지의 상담 버튼이 "상담 가능 / 잠시 중단"으로 바뀌는 기준을 여기서 정해요. 저장하면 1분 안에 반영됩니다.

1

요일별 시간

요일마다 켜고 끄고 시작·종료 시간 지정. 기본 평일 13:00–21:00, 주말 휴무.

2

휴무일

공휴일·휴가 날짜를 추가하면 그날은 중단으로 표시.

3

즉시 중단 스위치

즉시 중단을 켜면 시간표를 무시하고 바로 "잠시 상담 중단".

자주 묻는 질문

상담 중 브라우저가 꺼졌어요.

상담 업무를 다시 열면 입력한 내용이 그대로 있어요. 이어서 진행하면 됩니다.

고객이 하나도 안 보여요.

계정에 상담자 이름이 등록돼 있어야 본인 고객이 보여요. 관리자에게 이름 등록을 요청하세요.

같은 고객이 두 번 등록됐어요.

재연락 고객은 재연락 목록의 이어서 상담으로 열어야 같은 기록이 갱신돼요. 중복은 고객 목록에서 하나를 삭제하세요.

마감 담당 목록에 고객이 안 떠요.

수취 완료 + 기본정보 완료 처리까지 돼야 넘어가요. 계약 업무에서 두 단계를 확인하세요.

업로드/삭제했는데 화면에 반영이 안 돼요.

서랍을 닫지 말고 잠시 기다리면 반영돼요. 그래도 안 되면 새로고침.

화면이 옛 버전으로 보여요.
