상담 업무

말풍선을 읽으며 진행하고, 빨간 칸만 채우면 됩니다. 매장 주소·사업자번호·생년월일·이메일은 묻지 않아요 — 서류(사업자등록증·신분증·통장)에 다 있어요. 밴사도 언급하지 않습니다.

유입 경로 — 시작 전에 먼저Call-In 전화 문의 · Chat-In 채팅(카톡·채널톡) 문의 · Out 접수된 고객에게 우리가 연락. 인사말과 KPI 집계가 여기서 갈려요.
경로
  • Call-In→고객이 먼저 전화. 바로 1번 인사로.
  • Chat-In→채팅으로 들어온 문의. 통화 가능한지 먼저 묻고, 안 되면 채팅으로 1~2번 유형 판별까지만 진행.
  • Out→홈페이지·랜딩 접수 고객에게 우리가 전화. "○○에 남겨주신 커넥트 문의 보고 연락드렸어요"로 시작.
1
인사 · 기본정보녹음 고지 포함. 업종은 통화 전 네이버 지도로 봐둔 걸 확인만.
상담원안녕하세요, 우동지 {{ agentName }}입니다. {{ greetLead }} 통화 품질을 위해 녹음됩니다. "○○ 하시는 매장 맞으시죠?"
고객명 연락처 매장명 업종 업종 직접 입력 매장 주소 (선택)

바뀐 점 — 매장 주소·사업자번호·생년월일·이메일은 필수에서 제외. 매장명은 지도 검색·기록 식별용으로만.

2
유형 판별 — 질문 3개로 8유형 확정운영 여부 → 개인/법인 → 공동대표. 여기서 접수 링크·서류 목록·이후 단계가 전부 정해져요.
상담원"지금 운영 중이세요, 아니면 오픈 준비 중이세요?" 매장 구분
상담원"개인사업자세요, 법인이세요?" 사업자 형태
상담원"대표님 혼자 명의세요, 공동대표 계세요?" 대표 구성
상담원"연매출이 3억 넘으세요? 조건이 조금 달라져서 여쭤봐요." 연매출 3억
3억 이상 → 중고 단말기 990원 고지 필수. "대형 가맹점은 리베이트 규정 때문에 커넥트·단말기가 중고(거의 새것)로 월 990원에 나가요. 새 제품 원하시면 월 6,600원이에요." 미고지 시 박스 받고 철회하는 사례 있음. 모름이면 페이앤이 사업자번호로 판별해 채널톡으로 알려줌.

확정된 유형은 상단 배지와 오른쪽 패널에 표시. 페이앤 접수 링크 번호(payn.channel.io/workflows/…)도 자동으로 붙어요.

3
신규 오픈만 — 사업자등록증 · 오픈 예정일미발급이면 진행 불가. 오픈이 2~3일 뒤면 출고를 못 맞춰요.
상담원"사업자등록증은 나오셨어요?" 사업자등록증
발급 예정 → 오늘은 여기까지. "카드 가맹 심사가 사업자등록증 기준이라 나오시면 그때 바로 진행할게요. 언제쯤 나올까요?" → 하단 재연락 버튼으로 저장. 등록증 나오는 시점에 다시 세일즈.
상담원"오픈은 언제쯤이세요?" 오픈 예정일
오픈이 {{ daysToOpen }}일 뒤 — 카드 가맹·밴 전산 등록·전자서명·출고까지 최소 3~4일. "오픈 당일은 어려울 수 있어서 며칠 여유를 두고 잡아드릴게요."

인터넷은 보통 인테리어 때 같이 들어가니 신규는 4번의 인터넷 질문을 가볍게.

4
매장 환경 — 포스 · 약정 · 인터넷여기서 구성(5번)과 설치 방식(자가/현장)이 정해져요. 밴사·밴 조회는 언급하지 않습니다.
상담원"지금 포스는 어떤 거 쓰세요? 포스기, 태블릿, 노트북 중에요." 현재 포스
  • 아이패드→
    상담원아이패드는 저희 포스 프로그램이 안 올라가요. 커넥트랑 카드단말기만 옆에 두고 쓰시거나, 안드로이드 태블릿·PC 포스로 바꾸셔야 해요.
  • 노트북→
    상담원노트북은 연결 선이 복잡해서 연동은 안 해드려요. 커넥트+카드단말기만 따로 쓰시는 걸로 안내드릴게요. 매출은 밴사 앱으로 볼 수 있어요.
  • PC 포스 · 안드로이드→연동 가능. 5번에서 "포스 연동 필요" 체크 → 현장 설치.
상담원 · 기존만"지금 단말기 약정은 얼마나 남으셨어요? 계약서 보시면 나와 있어요." 약정 잔여
  • 10개월 미만·만료→
    상담원남은 위약금이 크지 않으시면 커넥트 0원으로 갈아타시는 게 이득이에요. 월 납부금이랑 남은 개월만 알려주시면 제가 바로 계산해 드릴게요.
  • 10개월 이상→
    상담원위약금이 아직 크시니까 지금 단말기는 그대로 두시고, 커넥트를 옆에 놓고 같이 쓰시면 돼요. 월 0원이라 부담 없어요.

    대리점에 위약금 전화하라고 하지 않기(방어 들어옴). 기존 대리점 문제 생기면 페이앤이 빠지는 조건.

상담원"카드단말기 놓을 자리까지 인터넷 랜선이 나와 있나요? 커넥트는 와이파이로 되는데 단말기는 랜선이 꼭 필요해요." 랜선
  • 랜선 없음→
    상담원단말기 자리까지 랜선만 하나 빼주셔야 해요. 연장선은 다이소·온라인에서 몇 천 원이면 돼요. 타공·배선은 인테리어나 인터넷 업체에 요청하셔야 해요.
  • 인터넷 없음→진행 불가. "인터넷 신규 가입이 먼저 필요해서 페이앤 쪽에서 인터넷 상담 연락드리게 할게요." → 마무리에서 페이앤 인터넷 상담 요청 체크. 우리가 인터넷 영업하지 않음.
5
구성 · 색상 · 청약 정보이번 단계 상품은 커넥트+카드단말기 0원만. 포스 신규는 조합가표 받은 뒤 추가.
상담원기본은 커넥트 + 카드단말기, 월 0원이에요. 배송으로 보내드리고 전원·랜선만 꽂으시면 돼요. 구성
상담원 · 포스 있음"쓰시는 포스 화면에서 결제 바로 넘기게 연동해 드릴까요?" 포스 연동
  • 배달앱→위젯만 띄워 쓰면 연동과 무관. 매출 합산 연동(배달매니저 등)을 원하면 월 이용료 별도라고만 안내, 현장 설치.
상담원"기기 색상은 화이트, 블랙 중에 어떤 게 좋으세요?" 색상

커넥트·프린터·금전함은 화이트/블랙 선택. 포스는 단일색이라 묻지 않음.

상담원네이버페이 청약에 들어가는 두 가지만 여쭐게요. "주로 뭘 판매하세요? 음식, 화장품, 옷 이렇게 크게만요." 판매 카테고리
상담원"네이버 아이디 알려주시겠어요? 대표님 개인 명의 계정이요. 비밀번호는 필요 없어요." 커넥트를 대표님 네이버 계정에 연결하는 데 쓰이고, 설치 후 우동지 플레이스 활용 가이드도 이 네이버 이메일(아이디@naver.com)로 보내드려요. 네이버 ID

이메일은 따로 묻지 않음 — 네이버 ID로 {{ naverEmail }} 자동 생성. 다른 이메일을 원하면 7번에서 수정.
